# 样图生成提示词（21 种风格 · 自造版）

> 创建：2026-08-17（第二步）。来源：对齐 vendor/srtvox-director 的 21 风格方向（方法论认可），
> 资产内容全部原创自造，不复制上游原图/原提示词（上游无 LICENSE，用户已定案走 Agnes 产线）。
> 用途：重出 `ref/style-assets/style-samples/` 里的 21 张风格样图。
> 正常流程不要读进上下文；选风格看 `style-library.zh.md` 总表，取风格块看各风格 guide.zh.md。

## 统一变量（21 条共用，唯一变量是风格本身）

| 项 | 值 |
|---|---|
| 画幅 | 16:9，1920×1080 |
| 题材 | 一段文字如何变成解释视频 |
| 四件物件 | 旁白稿纸 → 分镜条 → 参考图卡 → 时间线条，左到右等距 |
| 四处中文 | `文字变视频`（标题）· `脚本` · `参考图` · `视频提示词` |
| 载体 | 四个载体形状、材质、尺寸各不相同，覆盖 嵌入/粘贴/立牌/悬挂 四类 |
| 底部留白 | 8%，与字幕安全区一致 |
| 三层纵深 | 前景遮挡物 / 中景主信息 / 背景环境 |

## 出图后验收（对照 docs/review-checklist.md 参考图八项）

- 中文四处逐字正确；错了用该风格空白载体版重出，不改结构
- 载体四个形状明显不同，不得做成四个圆角矩形
- 三层分明，焦点色只落在当前主体上，不撒满画面
- 四件物件左→右顺序清楚；形状完整、无运动模糊

2. "脚本" 印在一条美纹胶带标签上，压平贴在稿纸一角 —— 粘贴类载体。
3. "参考图" 印在一块小印刷机牌上，机牌立在参考图卡旁的折纸底座上 —— 立牌类载体。
4. "视频提示词" 印在一枚纸吊牌上，用短绳挂在时间线条下方 —— 悬挂类载体。
四个载体的剪影、类别、尺寸必须各不相同。不得做成四个相似的矩形。

只渲染上面指定的文字。每一句都要完整、清晰、逐字正确。
不得生成其他文字、字母、数字、标识或水印。
画格、稿纸、时间线片段块上不得出现任何别的字符。

画面最下方约 8% 的横带里不放任何主体、载体或前景物件——这条带子里只有背景本身继续延伸，

- 前景、中景、背景严格按上面指定的分层，三层分明；
- 没有运动模糊；

- 不出现重复主体、融化的边缘、随意的装饰，或任何媒体标识；
