# 图片/视频验收清单（升级版，2026-08-17）

> 来源：srt-vox-director delivery-contract 第 8 节「用户自检表」（vendoring 快照内），
> 结构全收、表达重写。用途：review-images（MiMo 看图）的逐维度提示词 + 用户人工自检表。
> **MiMo 提示词模板正典在 `scripts/review-images.ps1`**（程序内嵌，按维度逐项提问），
> 本文件只列清单本体，不复制模板全文。

## 参考图八项

| # | 项 | 检查什么 |
|---|---|---|
| 1 | 画幅 | 与分镜表一致，且与后续视频画幅一致（16:9 横版） |
| 2 | 目标构图 | 参考图画的是本镜想呈现的核心画面，且是成立的构图、不是待填底板：层次与转场锚点完整，部件排布与提示词「目标构图」描述一致 |
| 3 | 主体数量 | 与提示词写的「精确主体数量」完全相同，没有多出的重复主体 |
| 4 | 文字 | 文字包里的每个关键词都已印在载体上、逐字正确、清晰可读；未列入文字包的表面全部留空（无乱码/错字/多余文字） |
| 5 | 连续性 | 与相邻镜的转场锚点位置、尺寸、颜色、方向一致 |
| 6 | 漂移 | 材质、调色板、光照方向没有偏离视觉圣经，没有滑向邻近风格；风格板格子/色卡/标签条没有漏进画面 |
| 7 | 无运动模糊 | 画面里没有任何拖影，否则视频模型会把模糊当材质，整片糊掉 |
| 8 | 形状完整 | 物体没有残缺边缘或断裂轮廓，否则动画时会扭曲、融化、闪烁 |

末两项（7/8）是图生视频专用，静态图看着没问题也要查。

## 视频片段六项

| # | 项 | 检查什么 |
|---|---|---|
| 1 | 开场状态 | 生成片的第 0 帧不必与上传图逐像素一致（上传图是垫图，模型会重新生成），但开场时各部件的位置符合视频提示词「开场状态」的描述 |
| 2 | 位移 | 至少三个主要部件有可见物理位移，不是只有光效 |
| 3 | 文字 | 载体整块移动，字符没有被逐字重绘、改写、闪烁；没有凭空长出新的字 |
| 4 | 终帧 | 终态与视频提示词描述的一致；末段绝对静止的长度符合该镜在尾部契约表里的那一档 |
| 5 | 数量 | 全程物体数量没有增减 |
| 6 | 桥接 | 拆分镜片段 b 的第 0 帧 = 片段 a 的末帧（抽帧时自动成立，单独出图时逐项核对） |

## 展示型镜头额外检查（视频）

- 入场时间按公式计算（min(生成时长÷3, 2.0s)），入场后**带字载体**保持稳定；
- 尾部是否加收束动作、末段静止多久，按尾部契约表的「展示型」档核对；
- 不得用呼吸亮度或背景平移**代替**带字载体的入场位移（禁的是顶替，不是禁止其出现）。

## 使用

```
# 批量 MiMo 看图（list 文件每行：路径<TAB>reference|video[<TAB>本镜补充说明]）
powershell -NoProfile -ExecutionPolicy Bypass -File scripts/review-images.ps1 -ListFile list.txt -OutDir out

# 人工自检：拿上面两张表逐条对照（程序查不了的语义项）
# 任何一项不过，只重生成失败的那一张/那一条，不要整批重来
```
