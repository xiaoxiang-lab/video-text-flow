# Woodcut Print · 提示词指南（木刻版画系）

适用题材：文化、农事、社会系统、民间技艺、传统故事。
气质：厚重、有匠气，有土地感。

## 风格块 A（标准镜头，逐字使用）

木刻版画舞台：印在暖调手工牛皮纸上，手工刻出的黑色线条带刀痕与颤纹。朱砂红与矿物蓝是仅有的两个专色，油墨压力不均，版边略有溢墨。背景每镜变化但始终保持牛皮纸主调。运动采用上墨、压印与抬版；每个镜头只有一个明确运镜。音频仅使用刻刀轻响、纸张摩擦与压印声。不要音乐，不要旁白。

## 文字注意

- 雕刻标题块（headline）、盖章边标（label）、立版标牌、编号印次签；中文短词，避免仿古落款。
- 有必须准确的文字 → 该镜配参考图。

## 哪几镜需要参考图

贯穿主体（刻版徽标/主图）、多元素空间关系要锁、有必须准确的文字、结构性镜头（开场/揭示/结尾）→ 配参考图；过渡/氛围/单主体 → 不配。

## 禁止漂移
