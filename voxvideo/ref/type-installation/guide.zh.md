# Type Installation · 提示词指南（字体装置系）

适用题材：片头、口号、概念解读、设计主题。
气质：硬朗、有机械感，信息本身就是舞台。

## 风格块 A（标准镜头，逐字使用）

实体动态文字装置舞台：厚印刷字块、导轨、弹簧、滚轮与配重。信号红单点强调当前字块，炭灰与生钢灰承担结构，暖米白墙面为底。中文词当作完整印刷字块处理，让文字通过物理排布解释关系。背景每镜变化但始终保持暖米白墙主调。运动采用压缩、堆叠与碰撞；每个镜头只有一个明确运镜。音频仅使用机械撞击、弹簧回弹与金属滑动声。不要音乐，不要旁白。

## 文字注意

- 印刷字块本身（headline）、导轨铭牌（label）、配重吊牌；中文短词整块处理，避免长句。
- 有必须准确的文字 → 该镜配参考图。

## 哪几镜需要参考图

贯穿主体（字块装置/品牌字）、多元素空间关系要锁、有必须准确的文字、结构性镜头（开场/口号/结尾）→ 配参考图；过渡/氛围/单主体 → 不配。

## 禁止漂移

- 不滑向邻近风格：见 style-gallery.md 分组目录与本风格「避免」栏互斥句。
- 材质系统、配色角色、三层纵深与本指南逐字一致，不混用其他风格元素。
