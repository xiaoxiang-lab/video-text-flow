# Museum Model · 提示词指南（博物模型系）

适用题材：历史、自然、城市、文化遗产、宏观系统。
气质：沉静、有仪式感，庄重而精确。

## 风格块 A（标准镜头，逐字使用）

博物馆微缩景箱舞台：置于中性暗色展厅内，聚焦暖色射灯、精确实体模型、层叠纵深。无玻璃的开放式陈列，安静的铭牌设计；亮度本身就是层级——前景失焦压暗、中景被打亮、背景暗至近黑。背景每镜变化但始终保持暗展厅主调。运动采用聚光揭示与模型升起；每个镜头只有一个明确运镜。音频仅使用展柜轻响、聚光启动声与低沉氛围声。不要音乐，不要旁白。

## 文字注意

- 展厅大展品牌（headline）、展品牌（label）、展厅标签、地面动线标；中文短词，铭牌字底明度差足够。
- 有必须准确的文字 → 该镜配参考图。

## 哪几镜需要参考图

贯穿主体（展品/景箱装置）、多元素空间关系要锁、有必须准确的文字、结构性镜头（开场/聚光揭示/结尾）→ 配参考图；过渡/氛围/单主体 → 不配。

## 禁止漂移

- 不滑向邻近风格：见 style-gallery.md 分组目录与本风格「避免」栏互斥句。
- 材质系统、配色角色、三层纵深与本指南逐字一致，不混用其他风格元素。
