# 视觉-封面生成

高级商业科技媒体编辑视觉封面。把标题/主题转译成一个「可读但不直白」的抽象实体意象，输出主图生成提示词 + 排版规范。

## 定位

- 本 skill 管「表层之图」，与「文案-标题入口」（表层之字）配合：**字图必须对齐同一个解码动作**
- 输入：**标题（逐字填写）+ 画幅（16:9 默认）** + 风格（默认瑞士平面；做视频封面时对齐正片风格）
- 画幅：输入项，默认 16:9，竖版/宽幅改输入值
- 输出：① 主图生成提示词 ② 排版规范（内置进提示词）

## 主图提示词结构（固化模板：只填标题 + 按风格换皮肤，核心创作任务原文不动）

**模板骨架（逐字使用，不得改动【核心创作任务】与【排版】的结构）**：

```
你是一位高级商业科技媒体的视觉总监。请根据下面的主题，生成一张高级、极简、可读的编辑视觉封面。

【输入】
主题 / 标题：<逐字完整标题>
画幅比例：<16:9 或按需>

【核心创作任务】
先理解标题背后真正要表达的关系、变化、动作或结果。
然后，把这个主题转译成右侧一个「可读但不直白」的抽象实体意象：
- 它必须由一个清晰的核心动作构成，例如连接、汇聚、对齐、推进、拆解、穿透、折叠、平衡、转化、生长或跨越。
- 画面中的物体需要有明确的隐喻关系，让观众即使不看标题，也能感到它在表达「某件事正在发生」。
- 右侧只讲一个视觉故事，使用少量精确的物体，不堆砌概念。
- 不要把主题直接画成图标、插画说明书或字面场景；要把它做成一个有材质、有结构、有动作的抽象小型装置。
- 可加入一位小比例、真实感的人物。人物负责与装置发生关键动作，例如调整、连接、推进、观察或完成最后一步。人物只作为尺度和行动感，不抢走主题。
- 如果人物会让主题变得多余或俗套，可以省略。

【固定视觉语言】
<按下方「风格皮肤整段替换」：气质/背景/配色/材质/构图/禁止>

【排版】
- 标题必须逐字准确使用：<再次粘贴完整标题>
- 标题使用<皮肤表的标题字体>，<皮肤表的主色>；可自动挑选标题中最关键的一个词或数字，使用<皮肤表的强调色>强调（建议强调<建议词>）
- 横向比例：标题在左，抽象意象在右；标题约占 50%–55%，意象约占 40%–45%
- 竖向比例：标题在上，抽象意象在下；仍然保持大面积留白和单一视觉中心
- 根据标题长度自动断行（建议断行：<断行位置>），确保中文清晰、无错别字
- 除标题外，不要生成任何可读文字、Logo、水印、副标题、边框或装饰性小字
```

**固定规则（实测确认）**：
- 只填「主题/标题」与「画幅」两个变量；【核心创作任务】用模板原文，**不锁装置、不改写**（实测：锁死装置的具体化版本效果差，模板原文给模型自由推导空间更好）
- 【固定视觉语言】按当期视频风格**整段替换**（皮肤表 → 气质/背景/配色/材质/构图/禁止全换）
- 【排版】只换：标题字体/主色/强调色/断行建议（按皮肤表），结构不动
- 每次交付明示所用皮肤：`封面皮肤：<风格名>（对齐正片/<用户指定>）`
- 画幅是输入项（16:9 默认），竖版/宽幅改输入值即可，无独立变体说明

## 风格对齐（做视频封面时第一件事）

**封面皮肤必须跟随正片风格，否则观众从封面进正片会跳戏。** 封面 = 正片的第一帧预告。

1. 先确定正片风格：问用户，或默认查 chupian-vox 风格库（`~/.config/opencode/skills/chupian-vox/style-library.zh.md` 总表）
2. 皮肤按正片风格替换（见下「风格皮肤表」），意象转译方法不变，只换皮肤
3. 无正片风格（文章封面/海报）→ 用下方「默认视觉语言（瑞士平面）」

### 风格皮肤表（色板/材质/字体，对齐 chupian-vox 风格库）

## 默认视觉语言（瑞士平面，仅无正片风格时用）

- 整体气质：高级商业编辑视觉、现代瑞士平面设计、克制的科技杂志感
- 背景：暖白、米白、略带细微纸张纹理
- 配色仅限四色：暖白、石墨黑、炭灰、低饱和半透明墨绿色
- 材质：哑光石墨金属、精密黑色模块、磨砂半透明绿色玻璃、柔和自然阴影
- 构图：安静、精确、大量留白，像一件被摆进画廊的编辑雕塑

## 双模式（先 A 后 B）

- **模式 A（默认）**：标题带字直接生图——提示词里包含标题与排版要求；出图后逐字核对标题，错字/掉字则重抽（最多 3 次）
- **模式 B（兜底）**：主图纯意象不带字，标题与封面文案在排版层加字（PS/Remotion/Canva）
- 何时切 B：A 重抽 3 次仍错字；或用户明确说「图不要字」。切换不用问用户，交付时注明用了哪种

## 核心创作任务

先理解标题背后真正要表达的关系、变化、动作或结果。然后转译成「可读但不直白」的抽象实体意象：

- 必须由一个清晰的核心动作构成：连接、汇聚、对齐、推进、拆解、穿透、折叠、平衡、转化、生长、跨越……
- 画面中的物体必须有明确的隐喻关系，让观众即使不看标题，也能感到「某件事正在发生」
- 只讲一个视觉故事，使用少量精确的物体，不堆砌概念
- 不把主题直接画成图标、插画说明书或字面场景；做成有材质、有结构、有动作的抽象小型装置
- 可加入一位小比例、真实感的人物，负责与装置发生关键动作（调整、连接、推进、观察、完成最后一步）；人物只做尺度和行动感，不抢主题；人物会让主题多余时省略

**动作必须存在（硬规则，模板第一性）**：意象必须是「正在发生某件事」的装置——核心动作（连接/汇聚/对齐/推进/拆解/穿透/折叠/平衡/转化/生长/跨越/安放/挂载）必须体现在装置上且可读。静态对比、纯构图不算动作。写完后自检：画面去掉标题后，观众能看出「某件事正在发生」吗？不能 = 加回动作（人物动作 + 装置动作）。

**意象必须从议题推导，模板只约束结构（硬规则，实测教训）**：模板的「装置+核心动作+人物动作+隐喻」是约束（结构），不是意象来源。装置本体必须从议题本质长出来——先写「议题本质一句话」（如「不是竞品，是底座 vs 应用的层级关系」），再从本质推动作（安放/挂载/层级），最后才落到装置（建筑落座到基座）。禁止：先挑模板动作清单里的一个动作，再反推装置（=模板驱动，实测翻车两次：尺子、门框推方块）。自检：意象推导链能一句话说清「议题本质 → 动作 → 装置」吗？说不清 = 模板驱动，重推。

**意象必须按风格皮肤的语言设计（硬规则，实测教训）**：装置的元素数量与形态必须匹配所选风格——
- vox 档案做旧：纸艺装置、多元素堆叠、撕纸拼贴（装置思维 OK）
- minimal-motion 极简：**巨型对比 + 极少元素（1-2 个）**，如「极小方块 vs 巨大方框」的尺寸对比本身就是主题；禁止把 vox 的装置思维硬套进极简风（标尺+刻度+模块+人形=6 元素 → 实测风格崩坏）
- fresh-scrapbook/warm-illustration/ink-scroll/blueprint-craft：按各自 guide 的材质语言
风格皮肤与装置设计的适配，在写主图提示词前先自查：这个装置如果只保留 2 个元素，主题还成立吗？不成立 = 元素太多，精简。

## 固定视觉语言（硬约束）

> 已拆为两套：上方「默认视觉语言（瑞士平面）」与「风格皮肤表」。硬约束适用于当前生效的那套——选风格皮肤时，以下四色/材质限制不适用，改用皮肤表的色板与材质；意象转译方法（核心动作/隐喻/人物尺度）两套通用。

- 气质（默认套）：高级商业编辑视觉、现代瑞士平面设计、克制的科技杂志感
- 背景（默认套）：暖白、米白、略带细微纸张纹理
- 配色（默认套）仅限四色：暖白、石墨黑、炭灰、低饱和半透明墨绿色
- 材质（默认套）：哑光石墨金属、精密黑色模块、磨砂半透明绿色玻璃、柔和自然阴影
- 构图：安静、精确、大量留白，像一件被摆进画廊的编辑雕塑

## 排版规范

- 标题逐字准确使用；高级中文无衬线字体，深石墨色（或皮肤表的标题字体）；自动挑选标题中最关键的一个词或数字，用强调色强调
- 横向：标题在左占 50%–55%，意象在右占 40%–45%
- 竖向：标题在上，意象在下；保持大面积留白、单一视觉中心
- 根据标题长度自动断行，中文清晰、无错别字
- 除标题外，不生成任何可读文字、Logo、水印、副标题、边框或装饰性小字

**⚠️ 排版必须内置（硬规则）**：模式 A 提示词必须把排版参数**烧进提示词正文**——画幅比例、左右占比、标题断行位置（逐字写死第几行是什么）、强调词与强调色、字体、无其他文字——生图模型只看提示词正文，不会看单独的「排版参数」章节。排版参数独立成节 = 生图时必然丢参数。变体（竖版/宽幅）作为「变体说明」附在文末，用户换画幅时按变体重出提示词。

**⚠️ 解码动作必须内置（硬规则）**：模式 A 提示词开头必须包含「标题」输入块（逐字），【核心创作任务】原文自带「先理解标题背后真正要表达的关系」——模型从标题+观点自行推导。生图模型看不到「解码动作」章节，若交付时预判意象会跑偏（尺子/门框教训：模型只能猜议题），在交付说明里提示用户，必要时可附一句隐喻提示（放在【核心创作任务】之后，不替换原文）。

## 工作流

1. **定皮肤**：做视频封面 → 对齐正片风格（查风格皮肤表），交付时明示 `封面皮肤：<风格名>`；文章/海报 → 瑞士平面默认。用户要换随时换（每期明示，不静默默认）
2. **填模板**：标题（逐字）+ 画幅（16:9 默认）→ 【固定视觉语言】按皮肤整段替换 → 【排版】换字体/主色/强调色/断行建议
3. 意象由模板【核心创作任务】驱动模型自由推导——**不锁装置**（实测：锁死装置的具体化版本效果差；模板原文让模型自己从议题推导更好）。但 AI 交付时仍要自检意象推导链（议题本质→动作→装置）是否成立、是否模板驱动翻车（尺子/门框教训），翻车预判时在交付说明里提示
4. 双模式：模式 A（带字直生）+ 模式 B（纯意象兜底，标题错字重抽 3 次仍失败时用）
5. 交付：主图提示词（模式 A/B）+ 所用皮肤 + **复核记录**（文件头附）：
   `复核状态：✅ 已复核（task 子 agent）/ ❌ 未复核`
   `检查项逐项 ✓/✗：风格皮肤对齐正片 / 标题逐字 / 双模式齐全 / 禁止清单命中0 / 色板与材质符合皮肤表`
   `异常N项 修正N项`
   无复核标记 = 未完成交付；禁止清单命中或解码动作不一致 → 重写后重交。
