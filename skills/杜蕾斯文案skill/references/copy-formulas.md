# 八个文案公式（含套用模板）

每个公式给出：**机制 → 杜蕾斯原例 → 迁移模板 → 非成人品类示范**。

---

## 公式 1｜谐音置换

**机制**：把热点里的一个字换成同音的品牌字/产品字，句子字面仍读得通。

**原例**
- 杜 / 独：「JOY LEAGUE 今夜不独行」
- 湿 / 十：「万湿如意」「杜杜湿乐园」
- 日 / 曰：「今晚，日【久】见人心」
- 尺 / 只：「尺杜允许，放胆去战」
- 「Just 比薄」（Justin Bieber × 小米比薄）
- 「杜 du 饿了」（baidu + ele.me）
- 「李所 ying 得」「首 ying」「梅开五杜」

**模板**：`热点固定短语` 中挑一字 → 换成品牌音 → 检查字面是否仍成立

**非成人示范（AI 课程）**
- 「AI 无止境」→「爱无止境」的反向：**「你与高手之间，只差一个『提示』」**（prompt 双关）
- 「不进则退」→ **「不 AI 则退」**

> ⚠️ 谐音是最低门槛也最容易烂俗的公式。一条文案里**只用一次**，用两次就变顺口溜。

## 公式 2｜数字双关

**机制**：热点自带数字 → 数字在你的语境里另有含义。

**原例**
- 「先来 7 次」（iPhone 7 发布会）
- 「This is 7 ?!」
- 「一日等于 24 小时」（科比 23→24 号球衣）
- 「Happy 1G24 Day」（1024 程序员节）
- 「点燃爱火，只需 001 点」（001 型号 ↔ 一点点）
- 年度报告体：「反复听了 69 次」「520 小时」「有 21 次他都在后面」

**模板**：`热点数字` + `你的产品里同样的数字` → 用一个动词把两者焊在一起

**非成人示范**
- 定价 199 的课 → **「199 天后你不会记得这 199 块，但会记得这门课」**
- 「3 小时」课程 → **「用 3 小时，换回你未来 3 年的加班」**

## 公式 3｜词义劫持

**机制**：找一个**正经场合的成语/术语**，其字面在你的语境里成立，然后只用字面。

**原例**
- 「深耕细作」「心急口快」（造句体）
- 「前方确认安全」（流浪地球）
- 「推进之前，安全工作已部署完毕」
- 「博弈的要素：策略与得失」（冯·诺依曼）
- 「撕开真相的面纱」（福尔摩斯）

**模板**：列 20 个行业黑话 → 逐个问「字面读是什么意思」→ 找出字面比本义更有画面的那个

**非成人示范（AI 课程）**
- **「幻觉」**：「不是 AI 有幻觉，是你以为你会用它」
- **「上下文窗口」**：「你的问题太长，它的耐心太短」
- **「微调」**：「不用微调模型，先微调你提问的方式」

## 公式 4｜场景移植（让物件开口）

**机制**：选一个**画面里本来就有、但没人注意**的物件，用第一人称让它说话，说的内容指向真正的主角。

**原例**
- 洗衣机说：爱的激烈程度，比我甩干衣服时还要强烈得多
- 床头灯说：作为夜班经理，希望他们给我加点工资
- 音响说：偶尔兼职当啦啦队员，为了制造氛围，做好辅助，我尽了全力

**模板**：`场景里的配角物件` +「说」+ `一句抱怨/骄傲/请求` → 读者自行推断主角在干嘛

**这是无实体产品时最好用的公式。**

**非成人示范（AI 课程）**
- **咖啡杯说**：以前他一晚要续我五次，现在放凉了都没人碰
- **打印机说**：我已经三个月没听过「帮我改一版」了
- **日历说**：他把周报那一栏划掉了，说以后不填了

## 公式 5｜拆字重组

**机制**：汉字本身是图形。拆开、重排、放大笔画，字义就变了。

**原例**
- 「『日』字有多长，从白天到黑夜罢了」（夏至，把「日」拉长）
- 春分「图解下『春』字」
- 「立，建始也；夏，假也」→ 今日宜生长，宜直立
- 「今亦球精 / 头头事到」（砖墙涂鸦，藏「精」「头」）

**模板**：把主题字写下来 → 拆偏旁 → 每个部件能否单独成词 → 重新造句

**非成人示范**
- 「智」= 知 + 日 → **「智能的『智』，是每天多知道一点」**
- 「AI」倒过来看像「IA」→ **「Intelligence Augmented：不是取代你，是加长你」**

## 公式 6｜对仗 / 宜忌体

**机制**：老黄历格式，`宜 XXXX` / `忌 XXXX`，四字为佳。或 `A 不如 B` 对比句。

**原例**
- 宜 | 颠三倒四 ｜ 宜 | 大动干戈 ｜ 忌 | 三心二意 ｜ 忌 | 倔强倨傲
- 堵在路上，不如堵在床上
- 买一百个，不如只买一个
- 挤在人群里，不如挤在被窝里
- 学走心事半功倍 / 学走肾技高一筹

**模板**：`大众正在做的事` + 「不如」+ `你希望他做的事` —— 两句结构完全对称，只换一两个字

**非成人示范（AI 课程）**
- **刷一百条 AI 资讯，不如跑通一个工作流**
- **宜｜动手实操　　忌｜收藏吃灰**
- **学工具事倍功半 / 学思路一通百通**

## 公式 7｜诗歌体

**机制**：三段景物白描 + 最后一句落到人。**景物与主题越无关，落点越有冲击。**

**结构**
```
[名词] [动词]
[修饰] [场景]        ← 第一段：远景

[名词] [动词]
[修饰] [场景]        ← 第二段：中景

[名词] [动词]
[修饰] [场景]        ← 第三段：近景

[转折句]
[落到「你/我」的一句]  ← 唯一有情绪的一句
```

**原例**：见 `corpus.md` 第四节 25 首全文。

**非成人示范（AI 课程）**
> 风穿过 / 深夜的写字楼
> 灯亮着 / 第七个未命名文档
> 光标闪 / 停在第一行
>
> 你以为差的是灵感
> 其实差的是一句会问的话

> ⚠️ 这个公式**最容易写成矫情**。检验标准：删掉最后一句，前面三段是否依然是合格的白描？如果前三段本身就在硬凑意象，整首废掉。

## 公式 8｜反向克制（最高级）

**机制**：在所有人都期待你耍花活的场合，**不耍**。用最朴素的一句话。

**原例**
- 中元节：**今晚早回家**
- 世界艾滋病日：**雨，都是在没带伞的时候下的**
- 交通安全日：**真正的司机，重视每一次安全**
- 艾滋病零歧视日：**歧视是人类文明的顽疾**
- 感恩节致百威：**感谢你让更多人，不用一个人从酒吧回家**

**模板**：识别「此刻不该开玩笑」的场合 → 说一句真话 → 一个字都不要多

**为什么有效**：一个一直很皮的品牌突然正经，**人格厚度**瞬间建立。这是长期人设的兑现时刻。

**使用频率**：全年不超过 5 次。用多了就成了鸡汤号。

**非成人示范**
- 行业裁员潮时：**「工具会淘汰工具，不会淘汰想清楚的人。」**
- 有人用 AI 造谣上热搜时：**「它只会照着你的样子回答。」**
