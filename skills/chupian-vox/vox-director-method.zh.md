# VOX 导演方法论（从教程视频蒸馏，2026-08-11）

来源：《VOX讲解.mp4》（四步法教程 + 太阳风极光示例片）与《VOX讲解-2.mp4》（题材玩法教程），
各 50 帧密采样 + 全文旁白转录分析。以下是可直接落地的规则，用于强化 voxvideo 的拆镜、
参考图提示词与视频提示词写作。

---

## 一、拆镜（脚本 → 视觉任务）

1. **一句一镜、一镜一个知识点**：每镜旁白 ≤9s（模型单段上限 10s）。
2. **给每句旁白定性**：这句话是「提出问题」「解释原理」还是「给出证据」？定性决定视觉任务——
   提问 → 问号/箭头/悬念元素；原理 → 结构/流程可视化；证据 → 数据/图表/档案素材。
3. **主体数量必须明确**：每镜声明「唯一主主体」，禁止重复主体。
4. **中文关键词保留字幕安全区**：画面右下留出字幕安全区，正文元素不侵占。

## 二、参考图提示词（结构化模板，比一句风格描述有效得多）

```
创建16:9图生视频参考图。唯一主主体是[材质+名称]，位于[位置]，占画面约[百分比]%。
[环境一句话：背景介质+主体关系]。右下留字幕安全区。
材质：[撕边纸、旧杂志网点、厚卡纸层次……具体材质清单]。
色板：[主色一、主色二、强调色……]。左上暖光。
允许文字：[点名允许出现的文字，只允许这些]。
画面只能出现[唯一主体]，禁止[额外天体类/重复主体/文字乱码/材质漂移]。
```

要点：
- 主体：**数量唯一 + 位置 + 占比（35% 这种具体值）**——模型最容易在主体数量上崩
- 材质与色板独立成句，光照写「左上暖光」（统一光源方向）
- 负面提示词**只写最容易出错的四项**：重复主体、额外元素、文字乱码、材质飘移；不用堆长
- 底部用标签摘要收尾：`[一颗地球] [主体35%] [右下安全区] [左上暖光]`

## 三、视频提示词（按时间轴写动作）

```
0—Xs [主体动作一] → Xs—Ys [主体动作二] → 结尾稳定0.8秒
```

1. **按时间轴分段写动作**：如「前 2 秒粒子高速推进 → 2-6 秒沿地球外侧弯曲绕行 → 6-9 秒沿磁力线进入两极 → 结尾稳定 0.8 秒」。
2. **三要素分开写**：主体动作（谁在动、怎么动）+ 镜头轨迹（镜头从哪开始、往哪移动）+ 结束状态（最后稳定 0.8 秒）。
3. **镜头不能代替主体运动**：只写「光点推进」模型不知道移动什么；要写清楚主体本身的变化。
4. 反面示范（模型常见失败）：只做几个光点和轻微推进——动作必须明确、单一。
5. **一次只做一个动作**（推近 / 展开 / 画路线 / 组装），动作越单一画面越稳定。
6. 音效直接写进提示词：纸张摩擦、快速掠过、低频环境音；模型原声先保留，后期混音调音量。

## 四、视觉语言库（同一主题可换题材/风格，靠锚点统一）

### 题材 → 视觉方案（来自教程 2）
| 题材 | 视觉方案 |
|---|---|
| 科普 | 剖面结构 + 显微世界（实物 + 红色标注箭头 + 放大圆窗口层层深入） |
| 历史 | 地图 + 旧报纸 + 人物档案（红绳连接照片与地点，俯拍档案桌） |
| 商业数据 | 折线 → 道路、柱状图 → 微缩城市（纸艺图表模型） |
| 产品 | 蓝图网格底 + 爆炸图（组件一层层拆开） |
| 人物故事 | 漫画格 + 证据墙 + 时间线（案卷墙拼贴） |

### 风格切换（同主题换画风不显乱的条件）
纸张拼贴 / 黏土定格 / 蓝晒图 / 水墨卷轴 / 极简动态图形 之间切换时：
**关键词、配色、转场锚点三者保持一致**——教程示例用「红色纸飞机」做跨镜统一锚点，
每镜背景换风格、锚点元素不变。

### 通用视觉元素系统（两片共通）
- 撕纸边标签（米色/牛皮纸）+ 黑色粗体字 + 指引细线指向主体细节
- 红色图钉固定卡片；红绳串联元素（档案/调查/关联感）
- 底部白色字幕（带阴影）；右下字幕安全区
- 深蓝背景（切割垫/蓝图/星点）与暖色主体的冷暖对比；或米白/米黄基底 + 高饱和红强调
- 纸张肌理：撕边毛边、纤维纹理、纸张厚度、柔和投影（左上光源）
- 时间轴条：牛皮纸条 + 红色圆点分隔「0-Xs 动作 → 结尾稳定」
- 教程/解释类构图：工作台俯视平铺（Flat Lay）、墙面信息板（mood board）、输入→处理→输出流程

## 五、剪辑（用户手工阶段，AI 出建议）

- **以旁白为时间轴**：先听旁白再决定切点（音频波形 ↔ 画面帧对应）
- 关键画面多停半秒；节奏 = 信息密度；重点 → 停顿
- 动作偏慢适当变速；对齐后混音（模型原声保留，音量分层）

## 六、全流程输出清单（skill 级交付，对齐教程的「Vox 视频导演」）

输入主题/时长/比例/单段上限 → 一次输出：
创意方向 → 旁白（原文逐字切分；开头钩子由「文案-标题入口」skill 前置定稿，本 skill 不写不改）→ 分镜 → 视觉规范（色板/材质/锚点）→
参考图提示词 → 首尾帧方案 → 分段视频提示词 → 运动/音效/负面提示词。

## 七、2026-08-12 GitHub 开源项目增补（vox-director / paper-collage-video / voxeasy）

### 图片提示词 5 段结构（比第二节模板更细的操作版）

```
① STYLE BLOCK（每镜逐字复用，全片统一就靠它）
② SCENE 描述为独立剪贴件（每个元素清晰边缘+独立投影 → 视频模型才能分层视差；
   融合成一团的场景只能整幅平移）
③ BACKGROUND 单一大胆平色（一镜一色，别用花背景，会糊掉剪影轮廓）
④ HEADLINE 短粗 2-3 词烤进图里（图片模型渲染文字远稳于视频模型；长文后期加）
⑤ TECH（16:9、2k）
```

### 视频提示词 5 轴 + 稳定性三轴

- 5 轴：GOAL（animate this still into collage motion graphic, flat 2D paper NOT 3D）+
  CAMERA（一个平滑连续运镜）+ MOVEMENT（分层纸片视差漂移/纸边胶带轻颤/半调点脉动）+
  AESTHETIC（保留撕纸/胶带/半调纹理）+ FEEL（本镜情绪）+ COLOR（本镜色板）
- 稳定性三轴（反崩关键）：
  - Motion amplitude：`very subtle, ~5% movement`，文字附近绝不用 intense
  - Dimensional lock：`flat 2D, camera parallel to the poster, no 3D rotation, no perspective
    change; paper layers parallax only, elements slide/pivot as rigid flat paper`
  - Stability anchors：`the printed headline and layout stay sharp, legible and perfectly
    stable — do not redraw, distort or move the lettering`

### 视频模型措辞规则（按模型区分）

- Omni / Veo / Runway：**正面措辞**，`no/don't` 会反噬（说不要 3D 反而更 3D）
- Kling / Seedance：支持负面提示词
- 通用：描述运动不描述画面（重述主体会触发重合成变形）；一镜一运镜一动作；单向运动给
  settle 端点（=我们的 0.8s 结尾稳定）；关键文字后期叠加

### ⚠ 真人+品牌标志的模型红线（实测）

- Omni 与 Seedance 的图生视频会**直接拒绝**名人脸与品牌 logo（"prohibited contents"），
  改 JPG、删名字、剪影化都绕不过——是图像内容检测
- 路线：① 真人/品牌镜改用 Kling O3 pro ② 本地逐帧引擎（无内容过滤）③ 被拒时去掉
  标志/真人描述重试
- C-roll 照片锁定模板（FACE LOCK）：`face and hair from the attached photo are cut out as
  a PHOTOGRAPHIC sticker, pixel-faithful; do not redraw, repaint or stylize the face; NO
  halftone dots on face or hair. All poses are expressed by the body only`——表情/动作只给身体，
  半调只作用于背景，服装必须锁定

### 表达方式路由（拆镜时每镜只选一种）

1. `direct` 直接呈现：有真实主体/过程/数据 → 直给（优先）
2. `story` 故事场景：有具体人物+事件 → 人物行动推进
3. `metaphor` 视觉隐喻：抽象关系/不可见机制才用；映射首帧到末帧不变
规则：能用真实主体讲清就不强行隐喻；画风只转译表达方式，不得反过来改变表达方式。

### 时间轴规则（与档位选型联动）

- 语义优先合并/拆分；**可长不可短**：选完整覆盖实际时长的最小档位（≤4→4、>4≤6→6、
  >6≤8→8、>8≤10→10），素材只能尾部裁短
- 字幕间停顿、开场/尾部空白必须保留；中文 220-240 字/分钟估时
- Prompt 前两句写风格+比例+时长；4/6/8s 最多两个动作阶段，10s 最多三个

### 转场意图表（用户剪辑时用）

continuity→slide 0.45s · location-change→wipe 0.5s · time-passage→page-turn 0.7s ·
focus-reveal→iris 0.55s · chapter-reset→shutters 0.65s · impact→cut 0s（纸边风格）
