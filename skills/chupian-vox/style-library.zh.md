## 选型规则（AI 判断，给用户确认）

1. **题材匹配**：先看文案讲什么 → 上表「适用题材」最贴的优先。
2. **语气匹配**：严肃数据/竞争 → vox；轻松日常 → fresh-scrapbook；情绪叙事 → warm-illustration；
   文化典故 → ink-scroll；拆解教学 → blueprint-craft；干货结论 → minimal-motion。
3. **拿不准时给用户 2-3 个候选**，说明各自气质差异，让用户定；候选从 24 风格里按七维打分挑。
4. 同一项目中途不得静默换风格；换风格 = 重新拆镜出素材包。
5. **样图展示纪律**：给用户看样图（`ref/style-assets/style-samples/`）时附文字描述
   （解释世界/最适用/载体/取舍），不一次抛全部；一开局说「你定」→ 默认三选
   （现代纸艺→黏土定格→毛毡手工，取第 1 个）；展示过三选后说「你定」→ 七维打分第一名。

### 七维打分（2026-08-17 吸纳 srt-vox style-selector，候选 ≥2 个时逐项打 1-5 分）

| 维度 | 问什么 |
|---|---|
| 语义契合 | 这个风格的解释世界能不能自然承载该题材 |
| 视觉清晰 | 主体和层级在手机小屏上是否立得住 |
| 关键词兼容 | 关键词载体（数字卡/标签/大字）是否都能在这个世界里自然存在 |
| 运动潜力 | 有没有真实的物理动作可写，而不是只能推镜 |
| 多镜连贯 | 换到第 8 镜时还认得出是同一支片子吗 |
| 生成难度 | 参考实测经验（LESSONS C 类：文字渲染/做旧先验） |
| 事实与文化风险 | 是否涉及需核实的史实、专业结构、宗教或民族元素 |

总分相同时优先生成难度低者。给用户 2-3 候选时，候选必须在**解释世界与运动逻辑上不同**（不能只换配色）；附一句默认建议「不选的话我用打分第一名开始」。

## 工作流（用户视角）

1. 用户给文案（一句话主题 + 完整脚本）。
2. AI 推荐风格（可带候选），用户确认。
3. AI 建项目：`python -m voxvideo init --topic <kebab> --script-file <path> --style <id>`
4. AI 读该风格 `guide_files`（每个风格一份 guide.zh.md），按风格语言拆镜 → design.json。
5. 其余流程不变：配音 → 参考图 → 审图 → handoff.md → 用户生成 → AI 合成。

## 风格文件结构（每风格 3 个文件）

- `config/styles/<id>.json`：注册元数据（guide_files / master_prompt_file / reference_files 样图）
- `ref/<id>/guide.zh.md`：风格块 A/B 逐字 + 参考图骨架 + 文字注意 + 参考图判断 + 禁止漂移
- `ref/<id>/master-prompt.zh.txt`：无文字风格母板（运行时文生图，参考图风格锚）

## 通用规则（所有风格都遵守，来自 vox-prompts 硬约束）

- 一镜一运镜、冲击拍独立主句（先…紧接着…）、落点收尾 + 尾部按差值分档（余量静止/补差末帧稳定）、深度至少两层
- 每镜换背景、配色不变；文字打类型标签（headline/label/giant number）
- 不要音乐旁白；音效写进提示词；原声保留后期混音
- 名人/特殊物件必须配形象参考图（LESSONS K 类）；真实标志写「扁平、不变形」
- 旁白 >9s 拆镜；一句一镜一知识点；右下留字幕安全区
- 参考图模板：主体唯一+位置+占比% + 材质/色板 + 光照 + 允许文字 + 负面四项 + 标签摘要
- 字幕走后期句级（whisper 时间戳 + ASS 烧录），提示词里不写字幕条
- **母板无文字**：风格母板（master-prompt）必须无任何文字，所有卡片面空白（LESSONS C4 教训）；
  生成后审图确认无文字再继续
- **文字渲染经验**（LESSONS C 类）：中文短词最稳；英文长词必掉字母换短词；做旧纸张强先验
  角落必出样例字（判定标准：核心大字正确+构图正确即可）；禁带字纸张背景；禁用「蓝图网格」类
  色系冲突背景

### 拆镜定型（2026-08-17 吸纳 srt-vox storyboard-algorithm 第 2 节）

**分镜前先给每一镜定型**，两型的处理路径完全不同，混用会出错：

| | 解释型 | 展示型 |
|---|---|---|
| 判据 | 旁白在**解释**某个东西（机制/步骤/对比/结论） | 旁白在**朗读**一块要给观众逐字读完的内容（引文/清单/代码/表格/截图） |
| 时长档 | 就近吸附（分界点见校验器，差值 ≤1.0s 硬规律） | 取最接近档，超 10 秒取 10（**不拆分**） |
| 超 11 秒 | 拆分 + 桥接帧（第 4 轮） | 不拆，封顶 10s；自然时长 >15s 按内容分成两个展示镜 |
| 上屏文字 | 密度控制，不逐字 | **必须完整覆盖本镜旁白，一字不压缩**——超长拆成多张卡（每卡 ≤14 字块），不是砍短 |

**三级优先级不可颠倒**：语义完整（一镜一个知识点）> 时长贴靶 > 差值最小。
为凑时长把两个知识点塞进一镜 = 最严重的错误。

拆镜时在作业表「型」列标注（解释/展示），程序校验（check_jobcard）。

**展示型拆卡规则**：上屏文字超 14 字块 → 拆成多张短句卡（每卡 ≤14 字块，落点在语义断点，
不是凑字数硬切），单镜最多 8 张卡；拆满 8 张仍装不下才分成两个展示镜。**一个字都不许压缩**。

**载体不撞形（子 agent 复核项）**：同一镜内没有两个文字载体长得一样——逐个写明形状/材质/
尺寸差异；≥3 个载体时至少覆盖 2 个类别（卡/牌/标签/贴纸/印章…）。拆到 6-8 张卡时按语义
分 2-3 组、每组一种载体形状，八张卡最容易做成八个一模一样的牌子。
