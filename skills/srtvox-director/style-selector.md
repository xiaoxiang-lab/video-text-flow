## 1. 从 SRT 提取选型输入

先通读 SRT 全文，再判断：

| 输入 | 取值 |
|---|---|
| 内容类型 | 科普 / 历史 / 教程 / 数据 / 产品 / 人物 / 文化 / 品牌 / 招募 |
| 观众情绪 | 好奇 / 信任 / 紧迫 / 温暖 / 悬念 / 惊叹 / 高端克制 / 活泼召唤 |
| 信息形状 | 机制 / 时序 / 对比 / 层级 / 路线 / 转化 / 证据 / 系统 |
| 主体类型 | 人 / 物 / 地点 / 数据 / 流程 / 抽象概念 / 纯文字教程 |
| 观众年龄倾向 | 少年 / 青年 / 通用 / 专业 |
| 文字密度 | minimal / standard / editorial-dense |
| 时长与镜数 | 由分镜结果给出 |

这是本 skill 相对同类工具的优势：**旁白全文开局就有**，选型不必靠用户口头描述去猜。

## 2. 七维打分

每个候选风格按 1–5 分打：

| 维度 | 问什么 |
|---|---|
| 语义契合 | 这个解释世界能不能自然承载该题材 |
| 视觉清晰 | 主体和层级在手机小屏上是否立得住 |
| 关键词兼容 | 关键词载体是否都能在这个世界里自然存在 |
| 运动潜力 | 有没有真实的物理动作可写，而不是只能推镜 |
| 多镜连贯 | 换到第 8 镜时还认得出是同一支片子吗 |
| 生成难度 | 参考 style-gallery 的实测评级 |
| 事实与文化风险 | 是否涉及需核实的史实、专业结构、宗教或民族元素 |

总分相同时，优先选实测评级更高的那个。

## 3. 推荐三选的硬要求

用户未指定风格时才推荐。三个方向必须**在解释世界与运动逻辑上都不同**，不能只换配色。

合格示例：科学切片（切开揭示）/ 剪纸剧场（层滑落位）/ 美漫风格（破格冲出）——
三种材质、三种运动、三种文字载体。

不合格示例：暖色纸艺 / 冷色纸艺 / 灰调纸艺——同一个世界换配色。

输出格式：

| 方向 | 解释世界 | 为什么适合本片 | 关键词载体 | 运动签名 | 取舍 |
|---|---|---|---|---|---|

附三张样图路径，并给出一句默认建议：「不选的话我用【打分第一名】开始。」

这里的默认值是**打分第一名**，不是风格库第一位 S01。
S01 只在用户一开局就说「你定」、根本没走打分时才用（见
[style-gallery.md](style-gallery.md)「默认三选」）。

用户已指定风格时跳过对比，只给一句选型理由，直接进入视觉圣经。

## 4. 自定义风格 DNA

```text
风格名：【简短原创名】
一句话世界：【什么样的物理世界在解释这个题材】
最适用：【内容类型】
观众情绪：【情绪】
时代或文化参照：【宽泛参照，不指名在世艺术家】
材质系统：【3–6 种材质】
调色板：【3–5 个颜色，各自的角色】
运镜：【角度、焦段感、纵深】
光照：【方向、柔硬度、对比】
主体构建：【主体由什么拼成】
关键词载体：【3–5 个本风格原生的载体类型】
字体行为：【尺寸、对齐、材质、描边】
运动物理：【物体如何移动与响应】
声音质感：【1–3 种材质音】
转场锚点：【物件 / 颜色 / 形状】
禁止漂移：【具体的失败形态，例如该风格容易滑向哪些邻近风格】
```

同镜内载体不得撞形是通用规则，逐镜在台账里落实即可（见
[prompt-keywords.md](prompt-keywords.md)），不必在风格 DNA 里写死每个载体。

用户给的是模糊描述（例如「中式未来但不要赛博朋克」）时，必须落成具体材质、
调色板、运镜、载体、运动，不要堆形容词。

## 5. 从参考图提取

用户提供参考图时：

```
1. 描述其版式、调色板、材质、光照、层级、运动潜力；
2. 把「可复用的设计原则」与「受保护的具体元素」分开；
3. 只用可复用原则构建原创 DNA；
4. 显式声明哪些不可复制。
```

不可复制的默认清单：品牌标识与名称、具体构图、可识别的人物或吉祥物、
在世具名艺术家的个人风格、已发布作品的逐帧还原。

自定义风格的**风格块本身也用中文写**，与风格库其余 21 条保持一致。

S17 就是这样从两张参考图提取出来的，可作范例。当时用户明确要求去掉角色，
DNA 里就写死了「禁止出现任何人物或吉祥物」。

## 6. 混合风格规则

主风格占全片 70–85%。副风格只用于**有叙事意义的层**：
档案证据、内部机制、回忆、未来态、对照组。

跨两种风格必须锁死：

- 画幅与运镜家族
- 主体轮廓、位置、方向
- 一个贯穿全片的强调色
- 标题安全区
- 转场锚点
- 每镜的最终落点

禁止一镜一换风格。切换必须落在叙事转折上，并在分镜表里标注切换镜号与理由。

具体的跨风格衔接提示词见 [style-library.md](style-library.md) 末节。
