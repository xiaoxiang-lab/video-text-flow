## 1. 视觉任务五类

每一镜必须且只能承担其中一类。这是可枚举的，因此可校验——
分镜表的「视觉任务」列只允许填这五个值之一。

| 类型 | 这一镜要让观众得到什么 | 典型画面 |
|---|---|---|
| 提问 question | 意识到一个问题或反差存在 | 并置两个不相称的东西、一个悬着的缺口 |
| 机制 mechanism | 看懂某件事怎么运作 | 剖开、观察窗、因果箭头、部件分离 |
| 证据 evidence | 相信某个说法有依据 | 文件、数据物件、对照实物、时间线 |
| 变化 change | 看到前后差别 | 同一构图的两态、堆叠对比、进度推进 |
| 结论 conclusion | 记住一句可带走的话 | 单一主体居中定格、标题卡落位 |

两条约束：

- 同一镜不得同时承担两类。需要用并列连词（并且／同时／以及／而且）才能描述完，
  就是两个视觉任务，必须拆镜。四个连词的清单以 storyboard-algorithm 第 10 节
  「机器可读约束」为准，两个校验器都据此判定。
- 相邻镜尽量不重复同一类，否则节奏会平。
  连续三镜都是「证据」时，检查是否该合并或改写其中一镜。

写进参考图提示词的「本镜视觉任务」字段，用中文值。
分镜表的 `视觉任务` 列仍写中英对照（如 `提问 question`），那是内部台账，`scripts/check_storyboard.py` 按英文部分匹配。

## 2. 视觉圣经模板

```text
为一支解释视频建立全局视觉圣经。

题材：【从 SRT 提炼的一句话】
用途：【科普 / 教程 / 招新 / 产品 / 品牌】
画幅与分辨率：【16:9 / 1920×1080】
选定风格：【ID + 名称】

定义：
- 运镜家族与焦段感；
- 主体尺度、位置、角度、精确数量；
- **前景 / 中景 / 背景规则**：三层各放什么类型的东西、各自的清晰度与明度关系、
  哪一层承载主信息、哪一层只做环境。全片统一，不得逐镜变化；
- 三到五个颜色及其角色（哪个只用于当前焦点）；
- 材质系统与纹理；
- 光照方向与阴影柔硬度；
- 标题固定区与字幕安全区（底部约 8% 留作字幕边距，1920×1080 下约 86 像素）；
- 关键词载体的类型与排版层级；
- 反复出现的转场锚点；
- 人物 / 地图 / 数字 / 图表的统一处理；
- **运动物理与声音质感**：部件落定是否回弹、材质响应、每镜保留哪一两个材质音；
- **禁止漂移**：本风格最容易滑向哪几条邻近风格，守住哪几件事就不会混
  （原文查 style-library 该风格块的「禁止漂移」栏）。
```

## 3. 关键词台账模板

写任何参考图提示词之前先出台账。**字段定义的正典在
[prompt-keywords.md](prompt-keywords.md)「关键词台账」**，下面这份模板逐字对应那一节列出的全部字段，
不得改名、合并或省略——早期版本把材质、层级、位置、对比揉进一个叫「处理」的字段，
层级和对比就在那一揉里丢了。

```text
镜 【N】
- 「【精确文字】」
  角色：主标题 / 核心关键词 / 短说明 / 仅后期
  载体：【风格原生物件】
  类别：嵌入 / 粘贴 / 立牌 / 悬挂
  材质：【纸 / 印泥 / 蓝图板 / 陶土 / 木刻版……】
  层级：主 / 次 / 三级
  位置：【画面分区，及与主体的关系】
  对比：【前景与背景的明度或色相关系】
  动作：【就位 / 盖章 / 别针 / 翻转 / 悬挂 / 展开 / 锁定 / 保持 / 抽出遮挡物露出】
  路线：generated / blank carrier + overlay / post only
- 「【精确文字】」【同上九行字段】
- 仅后期内容：【本镜完全不上屏、留给后期叠加的内容；无则写「无」】
```

最后那行 `仅后期内容` **不是第十一个字段**，是整镜级的一个补充说明：
十个字段描述的是**会上屏**的每一条文字，这一行收拢**不上屏**的部分。
（`仅后期` 同时也是「角色」字段的取值之一，用于某条文字虽然登记在册但不出现在画面上。）

每镜文字数上限与展示型的分组要求，正典见
[prompt-keywords.md](prompt-keywords.md)「三档密度」，本文件不复述数值。

同镜内没有两个载体长得一样，逐个写明形状差异；**≥3 个载体时至少覆盖 2 个类别**。

## 4. 参考图提示词模板

```text
为一支原创编辑感解释视频，生成一张 【画幅】 的图生视频参考关键帧。

题材：【一句话题材】
本镜旁白：【本镜旁白原文，逐字照抄 SRT 的 raw_text，不是清洗后的版本】
本镜视觉任务：【提问 / 机制 / 证据 / 变化 / 结论】
本镜知识点：【一句话，这一帧要让观众明白什么——写语义，不写画面。
从分镜表的「知识点」列原样带下来。旁白是比喻时，这里必须写出它真正在说的事，
否则模型会照字面画】
本帧角色：目标构图——这是本镜想呈现的核心画面，模型读它当垫图、重新生成第 0 帧并演化。
组装方向：【assemble 正向组装 / disassemble 反向组装】。

主体是【主体】，视觉化为【实体隐喻】。
精确主体数量：【数量】。
目标构图（assemble）：【这一镜要聚拢成什么样：哪些部件已在位、哪些还处于未落位状态。
无字部件可选：翘起 / 卷着 / 扣着 / 被遮住 / 堆叠 / 停在画面边缘 / 尚在画外；
**带字载体只能选画面内的那几种**，不得选「尚在画外」】。
目标构图（disassemble）：【主体已完整成型，画出可拆的分界：
接缝 / 转轴 / 分层线 / 盖板 / 封条 / 卡扣 / 边缘翘起的一道。
写明沿这些分界可以分离成【N】个完整部件。带字面板同样在参考图里就已印好】。
两行按组装方向二选一填，不要都留。

前景：【前景物件】，与中景之间有明显的空间距离，略微失焦，可切到画框。
中景：【主信息结构】，承载本镜主信息，对焦清晰。
背景：【环境与支撑信息】，位于画面深处，【清晰 / 虚焦】，不与中景争夺注意力。
连接元素：【箭头 / 拉线 / 路径 / 引线 / 并置对照 / 台阶或轨道】，
把【A】与【B】的关系讲清楚。它在这一帧就必须已经成立，不是等视频里才连起来。
视觉焦点：【唯一主角】——观众第一眼落在这里，画面里没有第二个东西跟它抢。

风格与材质：
【风格块，从 style-library.md **整段原样取用**，含「配色角色」与「三层纵深」两栏。
截掉那两栏，这条风格的三层约束就整条消失了——上面那三行只是通用兜底，
风格块里那份才是这条风格自己的前景物件清单】

随附的风格板只作材质与配色的依据：参考它的材质、配色角色、载体语言与厚度线索，
不复制它的分区版式、标签文字、样本方块与陈列方式。
本次要画的是一个完整场景，不是样板。

配色：【颜色与角色】。
光照：【方向与柔硬度】。
构图与视角：【近景可带透视 / 中景平视 / 纹理特写】——按本镜信息落在哪个尺度上选，
判据见下面的「景别按内容选」；风格块写死了视角传统的（等距轴测、俯拍桌面、
俯拍笔记本）不换机位，改用取景范围与主体占比做变化。
主体位于【位置】，约占画面【百分比】。前景、中景、背景三层在这个视角下都要读得出来。
信息按【左到右 / 中心向外 / 上到下】组织。
画面最下方约 8% 的横带里不放任何主体、载体或前景物件——这条带子里只有背景本身继续延伸，
材质与颜色和上方完全连续，不得画出白条、色块、色带、渐变、暗角或分界线。
成图里这条带子必须看不出边界。

精确上屏文字包：
1. 「【主标题】」印在【载体】上，【材质/颜色/描边/尺寸/角度/位置】，主层级。
2. 「【标签1】」印在【不同载体】上，【处理】。
3. 「【标签2】」印在【不同载体】上，【处理】。
4. 「【标签3】」印在【不同载体】上，【处理】。

只渲染上面指定的文字。每一句都要完整、清晰、逐字正确。
不得生成其他文字、字母、数字、标识或水印。不得把所有载体做成同一个样子。
若某处中文无法保证准确，就让**那一处**的载体完全留白，保持原有的设计、材质与位置，
交给后期叠字——绝不允许用编造的字符顶替。

转场锚点：【锚点】位于【位置】，保持【尺寸/颜色/方向】不变，供下一镜衔接。

硬性约束：
- 只有一个清晰的视觉焦点；
- 主体数量精确；
- 前景、中景、背景三层分明；
- 没有运动模糊；
- 形状稳定、完整、轮廓不断裂，适合后续动画；
- 不出现重复主体、融化的边缘、随意的装饰，或任何商业媒体标识；
- 不得复现某一帧已发布的画面。

避免：【本主体专属的负面，三到六项】
```

**提示词一律用中文写**，包括风格块、结构描述和负面约束。上屏文字本来就是中文，
不必再为了模型去切英文——切了反而容易让画面里的字被「翻译」成拼音或英文。

**「随附的风格板」那三行是本模板的固定成分，逐镜都要带上，不许省。**
风格板是 `assets/style-board/SNN-风格名`，出图时与提示词一起上传，
给模型一份可看的材质与配色依据，而不是只靠文字去猜「暖象牙纤维纸」是什么手感。
它同时也是风格一致性的锚——全片每一镜传同一张，比逐镜复述风格块可靠。

那三行是**反泄漏**用的：风格板是分区陈列的样板，六个格子、标签条、样本方块的版式很强势，
不加限定直接传上去，模型会把这套版式当成构图信息画进镜头。
用户平台不接受额外参考图、或用户选择不传时，删掉这三行，其余不变——
删的是这三行，不是风格块。

**这张图画的是本镜的目标构图。** 上传后模型把它当垫图、重新生成第 0 帧并演化到终态，
所以参考图画的是「想呈现的核心画面」，不强制是动作起点。正典见
[prompt-motion.md](prompt-motion.md) 第 6 节。三条落笔要求：

- 背景层、前景层、三层纵深、转场锚点在参考图里就必须完整成立，**不能是一块待填的底板**；
- 用「目标构图」那一行交代清楚各部件的排布与状态；
- **带字载体必须在参考图里就已印好、已可读**。让带字的东西在视频里从画外飞入，
  等于把造字任务交给视频模型，字必漂。无字部件不受此限。

本镜取 `motion_dir: disassemble`（分镜表标 `反组`）时，目标构图改画**完整成品**，
上面那三条落笔要求相应变成：三层与转场锚点照旧成立，主体已完整成型，
**分界必须画进图里**，带字面板照旧在参考图里印好。方向的定义与编排上限见
[prompt-motion.md](prompt-motion.md) 第 6 节。

**硬性约束七条一条都不能省。** 其中两条是图生视频专用：

- 「没有运动模糊」—— 参考图带运动模糊，视频模型会把模糊当成材质，结果整片糊掉；
- 「形状稳定、完整、轮廓不断裂，适合后续动画」—— 形状残缺或边缘断裂的物体，
  动画时会扭曲、融化、闪烁。负面清单里的「融化」是结果，这一条是原因。

三层纵深是画面厚度的直接来源，**不要退化成一行横向排列**。
前景放近物与遮挡，中景放主信息结构，背景放环境与支撑信息，三层要有明确的层级关系。

**纵深要落到具体的厚度线索上，而线索按风格取。** 只写「三层分明」模型做不出厚度。
纸拼贴靠落影与接触阴影，水墨靠三档墨色与留白，皮影靠透光边缘——
**每条风格的「厚度线索」字段是唯一正典**，见
[style-library.md](style-library.md)，本文件不列举各风格的做法。

### 景别按内容选，不按配额轮

全片十几镜用同一个机位会显平，但「每 N 镜插一个近景」是拍脑袋的配额。
决定景别的是**这一镜的信息在哪个尺度上**：

| 这一镜要观众看什么 | 景别 |
|---|---|
| 单个物件的内部构造、质感，或它完成一个动作 | 近景，可带透视 |
| 多个物件的关系、并置、流程、对照 | 中景平视（主力） |
| 段落之间换气，本镜不承载新信息 | 纹理特写 / 空镜 |

和视觉任务五类天然对应：`机制` 常落在第一行（剖开来看单个东西怎么运作），
`证据` 与 `变化` 常落在第二行（要并排比较），第三行多出现在段落交界，
也正好是换层转场的落点。

**四条硬约束压过上表：**

- **展示型一律中景平视。** 观众要逐字读完，景别一变字就难读；
- **带字载体多的镜不用大透视**，字随透视变形，视频模型跟着重绘就漂；
- **`变化 change` 的前后两镜必须同机位同构图**——机位一换，对比就不成立了；
- **相邻两镜不连用近景**，连着两个特写观众会失去空间参照。

再加一条：**风格块写死了视角传统的不得违反**（哪几条是，查 style-library 各风格块的机位描述），
那时的景别变化翻译成该风格自己的取景变化，而不是硬加透视。

兜底自检：**连续四镜以上同一景别时，回查有没有哪一镜本该给近景**——
判据是上表第一行，那一镜是不是在讲单个物件。这是复查提示，不是强制配额；
真的每镜都在讲多物件关系，全片中景就是对的。这条和「连续三镜同类视觉任务要复查」
是同一种自检。

### 装饰物件预算

画面丰富主要来自**物件数量**，不是文字数量。参考片里每镜可见物件五到十几个，
其中一多半不承载任何信息——纸屑、别针、虚线路径点、色号标注、空白卡片。
它们不进关键词台账、不计知识点、不受文字密度档约束，只负责把画面撑满。

**数量不是配额，是算出来的**——字多的镜画面本来就挤，再撒装饰就是过载：

```
解释型：装饰物件数 = 风格块的装饰上限 − 本镜关键词数，算出负数按 0 计
展示型：不走这个公式，按动感预算 B / C 档的无字部件处理（见第 5 节）
```

上限查风格块的「装饰物件」字段。**关键词数只数会上屏的条目**——
`角色` 为 `仅后期` 的条目、以及整镜级的「仅后期内容」那一行都不计入，
它们不占画面，把它们算进来会让视觉稀疏的镜头被误判成拥挤、装饰被错误清零。
于是 `minimal` 档（文字少）的镜自动拿到最多装饰，`editorial-dense` 的密集镜自动清零，
不必再逐镜拍脑袋。留白型风格上限本身是 0，算出来恒为 0，自洽。

**可选清单同样是风格属性**，查同一个字段。本文件只定三条通用约束：

- 一律**无字**。装饰物件上出现文字，等于绕过文字密度档偷偷加信息；
- 不得进入主体的视觉焦点区，也不得压住任何关键词载体；
- 放在风格块「三层纵深」允许的层里。有的风格明确规定某一层「此外什么都没有」，
  那一层就不能撒装饰物件。

留白型风格（如水墨长卷、极简几何、马克笔记）的预算是**零**——
它们的丰富度来自层次与疏密，往里塞装饰物件是拿别的风格的标准砸自己的立身之本。

不要写成一堵无差别的负面词墙。负面只针对本镜真实存在的风险。

不要制造自相矛盾的描述，例如同时写「远处的地球」和「地球是主体」而实际只要一个地球。

## 5. 图生视频提示词模板

```text
【画幅】，【4 / 6 / 8 / 10】秒，【景别】，【中等 / 中高】运动强度。

本镜旁白：【逐字照抄，与参考图提示词里那句完全相同】
画面对齐目标：【旁白说到「某个词」时，画面正好发生什么】——
只写真正需要卡点的那一两个词，不要给每个名词都配时间码；这一镜没有必须卡的词就写「无」。

—— 起始状态（开场）——
开场状态：【动作开始前各部件的位置——可以是参考图里的排布，
也可以是动作清单里描述的起点。模型重新生成第 0 帧时，就按这里描述起手】
冻结的是外观：每个物体的身份、数量、材质、配色、光照、风格，以及已印好的中文，
全片与参考图里完全一致，不得重绘、不得改风格、不得把某个东西换成别的东西。
放开的是位置：参考图里部件的位置、角度、缩放、遮挡关系、展开度，
必须按下面的动作清单发生大幅且清晰可见的改变——这正是本片要做的事。
允许新进入画面的物体只有动作清单里点名的那些，且它们身上没有任何印刷文字。
参考图里可见的每一个字符，全片保持不变；任何时刻都不得出现新的文字。

—— 主要动作 ——
主要动作：【本镜唯一最重要的那个变化，从分镜表的「主动作」列带下来】，
幅度要足够大——写清它从哪到哪、走多远，不写「轻轻移动」这类没有幅度的说法；
在【时间】秒前完成，带明显过冲与一次回弹。
时间码：0.0–【时间】秒，【主要动作的物件】从【起点】移动到【终点】，
位移约【距离】，旋转【角度】，落定时【回弹】。

—— 辅助动作 ——
辅助动作：【为主要动作服务的部件，按分时入场的先后列出；不需要就删掉这一行】。
辅助动作不得引入第二个知识点，也不得与主要动作抢注意力。
时间码：【时间】–【时间】秒，【辅助部件及其顺序关系】；
【时间】–【时间】秒，【标题卡或辅助部件作为一个完整实体移动】。
印刷字符牢牢固定在各自的载体上；不得对单个字符做动画、改写、拆分或形变。

焦点：【从哪一层或哪个部件，切换到哪个主体】，全片段只做一次焦点转移。

运镜：**只选一个**——【从 prompt-motion 第 4 节运镜库 11 种里选一个真正会动的机位，写清轨迹、速度、结束构图。解释型不许写「机位固定」，那是展示型的规则】。
全片段不做第二次转向、不切镜、不叠加第二种运镜。
运镜只能辅助物体运动，不能代替物体运动。

—— 停点（尾部）——
【关键动作截止 = min(自然时长, 生成时长 − 尾部契约表的「关键动作前需留」)】秒——关键动作到此为止。
【尾部：查 storyboard-algorithm 第 6 节的尾部契约表定档，
 把该档「每档的可粘贴文本」里的那段原样贴到这里。本模板不复制那些文本。】

—— 声音 ——
动作动词：【三个动词】
声音：只使用【材质音1】、【材质音2】；不要音乐，不要旁白，不要人声，不要歌词。

—— 验收 ——
最低验收标准：
至少三个主要部件发生**清晰可见的物理位移**，并完成飞入、展开、折叠、抬升、贴合
或锁定中的一个动作。光点、扫光、呼吸式明暗、缓慢推镜，都**不算**主体动画。

避免：文字被改动、改写、闪烁或形变；逐字单独动画；添加人物；物体数量变化；
融化；塑料质感；通用 3D；随机辉光；只有运镜没有物体运动；新增字幕；标识；水印；
末帧不稳定。
```

**「至少三个部件位移」与「主要动作只有一个」不矛盾，别读成打架。**
前者是**下限**，防的是「画面只有光在闪」；后者是**主次**，防的是「所有东西同时在动」。
两条各治一种失败，定位分别在 [troubleshooting.md](troubleshooting.md) 第 1 节与第 3 节。
一个合格的镜头是：一个主要动作**幅度最大、最清晰可辨**，其余部件分时入场为它服务，
合起来三个以上部件都动过，但观众全程知道该看哪个。
主要动作**不必排在最前**——先有一个铺垫性的入场、再由主要动作落定，往往比一上来就重击更好读。

**画面对齐目标只写一两个词，不要给每个名词都配时间码。** 时间点一多，
模型同时接到太多任务，结果是哪个都不准。这一镜旁白里没有必须卡的词就写「无」——
留空会让模型自己找一个词去卡。

**【景别与机位】不是默认填「正面平视」。** 逐镜按第 4 节的**景别判据**选
（讲单个物件的构造或动作 → 近景可带透视；讲多物件关系 → 中景平视；段落换气 → 纹理特写），
判据表、四条硬约束与兜底自检都在那一节，本节不复述。

**风格块正文里的机位描述是「主力机位」，不是全片唯一机位。** 风格块会被逐镜原样粘贴，
所以它写的那句「正面平视」每一镜都会带上——**这一镜取近景时，必须在风格块之后追加一句
覆盖**，例如「本镜为近景重音镜：机位贴近主体、允许轻微透视，其余材质与配色照旧」。
不追加这句，粘贴进去的风格块会把整片钉死在同一个机位上，这是「全片十几镜看着一样平」
最常见的成因。

例外是**风格块写死了视角传统**的那几条（等距轴测、俯拍桌面、俯拍笔记本），
它们的机位就是风格本身，不覆盖；这些风格的景别变化改用取景范围与主体占比来做。

**锁定块必须拆成「冻结外观 / 放开位置」两半写，不得合并成一句笼统的「保持一致」。**
合并写法（早期版本的「所有物体、位置、材质、配色全部与图中完全一致」）会被模型读成
连位置一起冻结，于是它只敢加光效——这是「画面几乎没动」的一个成因，
与参考图画成终态那个成因并列，定位见 [troubleshooting.md](troubleshooting.md) 第 1 节。
拆开写之后，冻结项与放开项各自可执行，模型不必猜哪一半才是真的要求。

**锁定块里不要出现「上传图就是第一帧」「画面从它原样起步」这类声明。**
上传图是垫图、模型会重新生成第 0 帧——对模型宣告「图就是第一帧」与实际行为冲突，
只会让它困惑。锁定块直接从「冻结的是外观」起头，提到上传图时说「参考图」。

**时间码一律按生成时长写；关键动作截止 = min(自然时长, 生成时长 − 该档需留)**，
「需留」查 [storyboard-algorithm.md](storyboard-algorithm.md) 第 6 节的尾部契约表，
本文件不复述数字。生成时长按就近吸附取档，可能比旁白长（余量）也可能短（补差），
两种尾部写法不同，理由见同一节。

**上面这版是统一模板**——上传图当垫图、模型重新生成第 0 帧并演化到终态，
终态由视频提示词的文字描述锁定，没有第二张图去钉。参考图角色与组装方向正典见
[prompt-motion.md](prompt-motion.md) 第 6 节。

**带字载体的动作只能是就位、贴合、压平、翻正、展开、抽出遮挡物露出、从画面边缘滑到落点。**
写成从画外飞入，视频模型就得自己造字。无字部件可以从画外飞入。

**本镜标了 `反组`（`motion_dir: disassemble`）时**，在上面的锁定块之后、动作清单之前，
插入 [prompt-motion.md](prompt-motion.md) 第 6 节「组装方向」那段可粘贴片段，
其余字段照常填。模板本身不变，反组只是换了动作流的方向。

**展示型镜头不用这个模板**，以入场加定格为主。以下是展示型的模板正典，
[storyboard-algorithm.md](storyboard-algorithm.md) 第 2 节只写要点、不重复本文本。
它的生成时长同样就近取档（超 10 秒取 10），入场时间按下面的公式算：

```text
【画幅】，【4 / 6 / 8 / 10】秒，机位固定，低运动强度。

本镜旁白：【逐字照抄，与参考图提示词里那句完全相同】
画面对齐目标：【旁白说到「某个词」时，哪一张文字卡正好落位】——没有必须卡的词就写「无」。

**冻结的是外观**：每个物体的身份、数量、材质、配色、光照、风格，以及已印好的中文，
全片与参考图里完全一致，不得重绘、不得改风格。
**放开的是位置，但只放开两处**：带字载体在入场段的位移，以及下面点名的无字部件。
除这两处外，画面里其余东西保持不动。
**带字载体**只有 0.0–【入场时间】秒这一次入场动作，落位后不再移动、不再改变角度与缩放。
**允许进出画面的只有下面点名的无字部件**：【无字部件及其动作，按动感预算取档】。
它们身上没有任何印刷文字，全程不得进入读字保护区，也不得遮住任何一个字。
任何时刻都不得出现新的文字。

声音：只使用【材质音1】、【材质音2】；不要音乐，不要旁白，不要人声，不要歌词。

读字保护区 = 每一张文字卡的外框再向外扩一圈，约卡片短边的 15%。

0.0–【入场时间】秒：文字块（在上传图里就已印好、已可读）从未落位状态
【入场动作】到位。
【入场时间】秒之后：带字载体定格；
【无字部件的动作时间码，全部排在【入场时间】秒之后，
并在末段绝对静止开始之前完成——展示型不适用关键动作截止公式，
这里的截止 = 生成时长 − 尾部契约表「展示型」那一档的末段绝对静止时长】。
再之后：查尾部契约表的「展示型」那一档，原样贴该档的可粘贴文本。
```

### 展示型的动感预算三档

「展示型 = 全程什么都不许动」是过度收紧。**真正必须锁死的只有带字载体**——
它一动，字就有被逐帧重绘的风险。无字部件动起来不伤读字，还能救回画面的活气。
按本镜的读字负担取档，默认 B。**A 档条件优先于 C**——文字卡拆到 6 张以上一律走 A，
不再看语义能不能分组：

| 档 | 用在 | 无字部件 | 运镜 |
|---|---|---|---|
| **A 静读** | 代码、表格、密集数据，或文字卡已拆到 6 张以上 | 无 | 机位固定 |
| **B 点缀**（默认） | 引文、清单、对照，文字卡 1–5 张 | 一到两个，只在读字保护区外活动 | 机位固定，背景层可自身极缓平移一次 |
| **C 分卡揭示** | 文字卡 3–5 张且语义可分 2–3 组，且未命中 A 档条件 | 同 B | 机位固定 |

**C 档的分批入场不改变入场时间公式**：总入场时间仍是
[storyboard-algorithm.md](storyboard-algorithm.md) 第 2 节算出来的那一个值，
2–3 批在这个窗口内均分，每批落位即锁死。窗口不许为了分批而延长——
延长就是拿读字时间换动感，方向反了。

**无字部件的动作清单不在本文件**，正典在
[prompt-motion.md](prompt-motion.md) 第 3 节的「展示型的无字装饰动作库」——
动作库一律归 prompt-motion，本节只负责取档。那一节同时写明了它的硬约束、
以及它为什么不计入知识点与最低验收标准。

B / C 档与收束动作可以同时用：无字部件的进出排在前，收束动作排在末段静止之前。

**「背景层平移」不是运镜库里的「视差推拉」。** 运镜库那条指的是机位移动带来的
三层错动（prompt-motion 第 4 节），这里机位不动，是背景图层自己动。
写提示词时别把两者的文本混用，否则会同时出现「机位固定」和「推拉」两个要求。

**入场时间的公式、各档取值与封顶理由，正典在
[storyboard-algorithm.md](storyboard-algorithm.md) 第 2 节「展示型镜头的视频提示词」**，
本文件不复述——上面模板里的 `【入场时间】` 按那一节算出来再填。

带字载体定格是为了让观众读字，但画面不必全程冻死：余量够大时加一次收束动作，
末段再绝对稳定供剪辑定格延长。**阈值与秒数一律查
[storyboard-algorithm.md](storyboard-algorithm.md) 第 6 节的尾部契约表**，本文件不复述。

## 6. 桥接帧片段

拆分镜头时追加到两条提示词里。默认走抽帧：片段 b 的上传图就是片段 a 成片的末帧，
路线见 [prompt-motion.md](prompt-motion.md) 第 6 节。

上游片段结尾这一段决定抽出来的帧干不干净，不能省——它就是尾部契约表最后一行，
文本在 [storyboard-algorithm.md](storyboard-algorithm.md) 第 6 节「每档的可粘贴文本」，
原样取用。

下游片段开头：

```text
上传的这张图是桥接帧【B-ID】，它从上一条片子的末帧逐像素截取而来。
在【时间】秒第一个动作开始之前，
不得改变布局、物体数量、缩放、角度、阴影或任何可见文字。
不得用叠化或形变过渡到它。
```

中段（片段内部从一个状态到另一个状态时）：

```text
新的排布只能通过运镜、遮挡、展开或物理组装来揭示。
不得让一个物体溶解成另一个，不得液态形变，不得改变任何物体的身份。
每一个出现的元素，都必须是**一个完整的物体进入画面**，或者是被揭开露出来的，
绝不能由已有物体变形而来。
```

这一条防的是模型用「溶解 / 形变 / 一个东西变成另一个东西」来偷懒完成状态切换。
纸、木、陶这些材质一旦发生液态形变，整个风格就垮了。

## 7. 全局负面约束

按需挑选，不要整段粘贴。

```text
避免：重复主体、物体数量变化、中文被改写、随机字母、标识、水印、边界融化、
被换成塑料或金属质感、通用 CG 感、身份不稳定、闪烁、黑帧、关键物体被裁切、
只有运镜没有物体运动、只有光点在动、风格漂移。
```

精确数量必须正反两说：

```text
画面中恰好有一个【主体】。不得出现第二个【主体】，也不得出现
【近似物1】、【近似物2】、【近似物3】。
```

## 8. 无效写法对照

| 无效 | 有效 |
|---|---|
| 不要留空 | 底部加一排标本架，每块底座留空白 |
| 要有动感 | 纸卡起始时翘在画面左缘，滑到落点 140 像素，顺时针转 3 度，回弹一次后停稳 |
| 载体要多样 | 本镜三个载体形状、材质、尺寸各不相同 |
| 不要出现多余文字 | 未列入文字包的卡片、清单、表格只允许抽象线条；看起来想要文字的表面一律留空 |
| 不要重复 | 画面中恰好一个地球。不要出现第二个地球、月亮、行星或远处天体 |
| 要超现实 | 旁白稿纸放大到八倍，脚下站一个小人抬头看它 |
| 保持风格一致 | 用风格块里的核心材质描述锁定，例如「真实纸纤维、撕边、丝网印颗粒、卡纸厚度与接触阴影」 |

左列都是模型无法执行的形容词，右列都是可以直接照做的物件或动作。

### 写作准则

上面那张对照表回答「这句话能不能执行」，下面两条回答「约束本身该怎么写」。

**区分结构性约束与创意性约束。** 结构性（构图、载体、留白、数量）越细越好，写死；
创意性（要超现实、要有张力）只给**一个**具体示例，留出设计余地。
判据：新版概念更准但更难看，说明创意约束过密，回退改轻。

**不确定的事标注 `待核实`。** 平台可用时长、配额、价格、界面按钮名、模型版本、
专业领域数字，一律标注，并说明以实时界面为准。
