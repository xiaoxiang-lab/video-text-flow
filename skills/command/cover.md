用户要求做视频或封面。**输入一律视为「素材」**：文案、标题、话题、数据都可能是素材——立场必须是你（用户）的立场，不是素材自带的。

## 关卡0 · 立场确认（核心关卡，两个问题）

1. **AI 复述**这份素材/文案的立场是什么（一句话）
2. **你认不认同这个立场？**
   - ✅ **认同** → 提炼主张（= 素材立场）→ 继续关卡2
   - ❌ **不认同**（但喜欢标题/话题/数据）→ 走「立场重写」：
     a. 你给出/商量出**你的立场**（冲突理论：立场鲜明、有冲突、可反驳）
     b. human-writing 按你的立场重写正文：**保留事实/数据/时间线/话题方向，替换立场表达**（结论、判断、论证方向、设问）——重写是重新论证，不是润色；以「我」为主语，其他观点压缩成靶子
     c. **关卡1 立场重写稿确认**（产出文件 01-立场重写稿.md）：立场=你的立场？事实没丢？→ 确认后继续
   - 你直接给立场/标题候选 → 路径2（human-writing 按立场从零写正文 → 关卡1 确认）

## 关卡2 · 分镜稿 + 标题方案

- 可拆性自查（human-writing 分镜稿模式 5 条标准）→ 不达标出分镜稿（每句标注来源 + 子 agent 复核留痕，产出 02-分镜稿.md）
- 标题方案 A/B/C（「文案-标题入口」按立场出）→ 用户选
- **风格确认**：给 2-3 个风格候选（chupian-vox 风格库），说明气质差异 → 用户定，不默认

## 关卡3 · 配音定稿

hook（可拆 + 立场与正文一致 + 不杜撰）拼进正文开头 → 完整定稿全文确认（产出 03-配音定稿.md，不是只确认 hook）

## 关卡4 · 封面

visual-cover（风格对齐正片）→ 封面文件独立确认（产出 04-封面出图提示词.md）

## 关卡5 · 拆镜作业单 + 核对表

VOX 拆镜 → 拆镜作业单（时长/参考图/贯穿装置）+ 子 agent 核对表 → 确认（产出 05-拆镜作业单.md）

## 交付文件命名（test/项目目录内按关卡编号，用户能一眼看懂流程进度）

01-立场重写稿.md → 02-分镜稿.md → 03-配音定稿.md → 04-封面出图提示词.md → 05-拆镜作业单.md

## 硬规则

- **关卡完整性**：每个关卡独立交付、独立确认，禁止合并或跳过
- **立场一致性**：hook/标题/封面/拆镜的立场 = 关卡0 确认的立场（你认可的），防标题党
- **narration 边界**：VOX 逐字切分定稿全文；立场问题在源头（human-writing 重写）解决，不在 VOX 环节补
- 每份交付物带「复核记录」块（无标记 = 未完成交付）
